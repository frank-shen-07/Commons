# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People discovering and downloading open-source desktop software, including people without technical knowledge. Developers publish through a teammate-owned portal.

## Product Purpose

Make the journey from discovering an application to choosing a compatible download understandable and trustworthy.

## Capabilities and Constraints

Next.js App Router, React, TypeScript, Tailwind CSS. Frontend ownership only. Preserve the existing replaceable API adapter and working search. Backend, GitHub OAuth, release ingestion, and publishing logic belong to teammates. All development fixtures must be clearly labeled. No invented ratings, download counts, verification, dates, installation success, or popularity.

## Brand Commitments

Commons is the existing product name. The latest user brief replaces the dark Raycast direction with a light-first editorial marketplace: 60% Mac App Store, 25% Raycast, 15% Setapp. Create a distinctive identity without copying branding or exact layouts.

## Evidence on Hand

Six sample app listings in lib/fixtures.ts. No live marketplace API or distribution contract has been supplied. Official developer websites are the download fallback. Screenshots should come from real applications with provenance.

## Accessibility & Inclusion

Keyboard operation, visible focus, readable contrast, reduced motion, and responsive layouts at 1440, 1024, 768, and 390 pixels.
