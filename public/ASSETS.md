# Asset provenance

Screenshots are genuine application screens from official project websites, displayed at a different scale. Original image files have not been edited. Each downloaded asset has an adjacent provenance JSON file naming the exact URL.

- OBS Studio screenshots and icon: OBS Project, https://obsproject.com/. Screenshots show the capture interface and scene controls. Application name and marks belong to their respective owners.
- LibreOffice Writer and Calc screenshots and Writer icon: The Document Foundation, https://www.libreoffice.org/. Website images are provided under Creative Commons Attribution-ShareAlike 3.0 unless otherwise specified: https://creativecommons.org/licenses/by-sa/3.0/. Original files are retained; only their display size/crop changes.
- Inter font: Rasmus Andersson and contributors, distributed by Google Fonts under SIL Open Font License 1.1. Fonts are served from /fonts/ and make no browser request to Google.

All other app icons are consistent Lucide illustrations used as fallbacks, not claimed to be the projects’ official branding. No generated or stock software screenshots are used.
